# gsutil

#### gsutil

> gsutil 是一个 Python 应用，该应用可让您通过命令行访问 Cloud Storage。您可以使用 gsutil 完成各种各样的存储分区和对象管理任务，包括[^1]：
>
> 1. 创建和删除存储分区。
> 2. 上传、下载和删除对象。
> 3. 列出存储分区和对象。
> 4. 移动、复制和重命名对象。
> 5. 修改对象和存储分区 ACL。
