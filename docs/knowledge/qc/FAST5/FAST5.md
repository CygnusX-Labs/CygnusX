### 1 Introduce

The \*\*FAST5 \*\*format is the standard sequencing output for \*\*Oxford Nanopore sequencers \*\*such as the MinION. It is based on the *hierarchical data format* [HDF5](https://en.wikipedia.org/wiki/Hierarchical_Data_Format "HDF5") format which enables storage of large and comples data. In contrast to fasta and fastq files a FAST5 file is binary and can not be opened with a normal text editor.[^1]
