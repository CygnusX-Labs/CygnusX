# 快速入门



欢迎使用 OmicHub 实验室知识库！

## 什么是 OmicHub

OmicHub 是面向生命科学研究团队的私有化多组学分析平台，整合 RNA-seq、ATAC-seq、ChIP-seq、单细胞测序、全基因组测序等主流分析流程。

## 首次使用流程

1. **上传样本数据**：进入「数据管理」页面，上传原始 FASTQ 文件或样本信息。
2. **选择分析流程**：在「分析流程中心」浏览并选择适合您研究需求的流程。
3. **提交任务**：填写参数后一键启动 Snakemake 工作流。
4. **查看结果**：在「任务中心」实时监控进度，完成后下载报告。

## 常见问题

### 如何查看任务日志？

点击任务列表中的「详情」按钮，切换到「实时日志」标签页即可查看。

### 任务失败怎么办？

请检查：
- 输入文件路径是否正确
- 样本信息是否完整
- 工作目录磁盘空间是否充足

如仍无法解决，请联系管理员。
