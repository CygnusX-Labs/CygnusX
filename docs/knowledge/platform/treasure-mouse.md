# 寻宝鼠（科研数据发现）页面指南

## 快速结论

寻宝鼠是 CygnusX 的对话式科研数据发现助手，页面入口为 `/treasure-mouse`（左侧导航「寻宝鼠」）。
本页面介绍寻宝鼠的主要功能、使用流程和执行边界。它帮助用户从科研问题出发，检索公开组学
数据库和文献，解释数据集与编号，并把发现结果整理成可审阅的数据获取或分析预案。寻宝鼠负责
“发现与准备”，不直接替代下载、分析或报告执行。

## 主要功能

| 场景 | 可以做什么 | 示例 |
| --- | --- | --- |
| 数据发现 | 从研究问题出发，检索 GEO、SRA、ENA、GSA 等公开数据源，返回相关数据集与证据 | “寻找干扰素应答相关的高通量测序数据” |
| 编号溯源 | 输入 SRR、GSM、GSE、BioProject 等编号，定位原始项目、样本与关联记录 | “SRR21857241 属于哪个 BioProject？” |
| 数据集解读 | 解读实验设计、样本分组、元数据与数据规模 | “GSE282210 的实验分组是什么？” |
| 文献探索 | 检索 PubMed、Europe PMC 等文献来源，整理相关研究与证据链 | “查找 mRNA 疫苗免疫应答的转录组研究” |
| 预案准备 | 基于发现结果生成下载或分析预案，交由人工审阅和批准 | “为这个数据集准备下载预案” |

页面还提供会话列表、寻宝排行榜、使用统计和主题切换等辅助功能。

## 使用流程

1. 在输入框描述科研问题，或直接粘贴论文链接、DOI、PMID 或数据编号。
2. 寻宝鼠检索公开数据库与文献，返回候选数据、编号关系和证据摘要。
3. 需要获取数据时，生成下载或导入预案；预案不会自动执行。
4. 人工确认预案后，才进入下载、Dataset 导入或分析准备流程。
5. 实际执行还受项目权限、数据来源和运行门禁限制。

## 边界与注意事项

- “能发现”不等于“能下载”：寻宝鼠可以检索和准备预案，实际下载由下载模块执行。
- 预案不是授权：未经过人工批准不会创建下载或分析任务。
- 当前环境可能处于运行门禁保护状态；即使批准预案，也可能因未通过执行验收而不创建任务。
- GEO processed matrix、仅含 counts 的表达矩阵和任意 URL 不能直接作为原始测序数据下载。
- 身份、项目与权限由平台服务端派生，助手不能代替用户提升权限。

## 与平台其他入口的关系

- 数据下载：把选定的公共数据真正取回并登记为文件。
- 分析中心：对已准备好的数据提交声明式分析流程。
- 实验室知识库：保存方法、SOP 和平台使用说明；寻宝鼠的检索结果不等于知识库证据。

## 常见问题

**寻宝鼠能直接下载数据吗？**

不能直接下载。它负责发现数据、核验证据并准备预案；下载由平台下载模块在人工批准和运行门禁
允许时执行。

**为什么批准预案后没有创建任务？**

可能因为当前环境未通过执行验收、项目权限不足、数据来源不受支持或预案缺少必要元数据。
页面会显示具体阻断原因。

**寻宝鼠和 AI 助手有什么区别？**

寻宝鼠专注公共科研数据与文献的发现、编号溯源和预案准备；AI 助手负责平台使用问答和通用
分析协作。需要正式下载或分析时，从寻宝鼠生成预案并完成人工审批，再进入对应模块执行。
