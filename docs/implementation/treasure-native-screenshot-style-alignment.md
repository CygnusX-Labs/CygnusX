## 当前实现

- `TreasureResearchWorkbench.vue` 使用铺满内容区的暖米白纸感点阵；默认 48px 会话窄栏，点击展开历史列表。移除外层卡片框和工作台内边距。顶栏为紧凑品牌与操作区；项目选择进入弹层，刷新权限和阿寻显示开关均有实际回调。
- 对话区居中最大 768px，用户提问为右侧绿色气泡与用户头像，助手为品牌头像、检索胶囊和白色回复卡片。Markdown 使用平台已存在的安全渲染组件。复制按钮连接真实剪贴板，仅成功后显示已复制。
- 原 Composer 在有消息时固定于底部布局，不随消息列表滚动；空会话保留原 EmptyState 的四场景入口。新会话不会伪造参考截图中的提问、工具结果或回复，实际发送后才切换到会话态。
- 展示 Island 新增受控 pet 模式，直接打包原鼠形象；流式中显示挖土姿势（暗色为提灯），结束后回到基础形象。气泡只描述当前正在检索，顶栏可收起/找回。此处未复刻完整旧桌宠状态机、成就统计或旧账号偏好。
- 修复原工作台流式助手对象在 reactive 数组之外直接修改的问题：将该消息自身设为 reactive，确保增量正文在流结束前显示。列表接近底部时跟随增量；向上阅读时不强制拉回。
- Vue 继续持有项目、会话、草稿、鉴权和 SSE；未导入旧 React SPA 的身份、存储、网络客户端。结果提案协议与执行门禁未改。排行榜、统计、语言等旧 SPA 全部功能尚不等同于已迁移，未增加假按钮。
