# S3 下载网络、预算与日志安全增量

结论：局部修复已落地，G3 未通过，整体架构调整尚未完成。源码传输门禁保持关闭；没有部署、启动下载器、访问下载目标或连接生产数据库。

## 本轮变更

- 公网主机语法收紧，拒绝非法标签、规范化后数字地址别名、超长链接和过多查询字段。DTO 拒绝常见签名/凭据查询与云对象查询；没有引入凭据明文保管或声称存在安全保险库。
- 既有 BinaryExecutor 添加默认关闭的调用方日志过滤器。下载调用在 stdout/stderr 缓存、日志回调与 Worker 日志持久化/发布入口过滤 URL、Cookie、Authorization 和常见密钥。保留原始 JSON 进度解析，不新增传输实现。
- 下载 Task 响应脱敏展示副本；原任务参数、执行参数及确认哈希不改写。下载校验错误去除原始 input/ctx/msg；确认存储前进行 DownloadRequest 校验，HTTP 确认端点返回固定错误。
- 工作区先前已有公网地址/重定向策略函数、FTP 限深/条目/超时和源码关闭门禁。FTP 展开结果现按 `min(max_ftp_files, max_links_per_task)` 限制，禁止目录展开放大请求链接上限。本轮保留并回归，不能把这些函数或 fixture 当成已生效的网络隔离。
