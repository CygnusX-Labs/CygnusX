# CygnusX 首页字号可读性优化记录

针对首页字体整体偏小的反馈，在现有首页层级与布局上调整字号、行高和文字色，不改变浏览器缩放、全站字号、侧栏和其他业务页。

## 字号层级

| 内容 | 调整前 | 调整后 |
| --- | --- | --- |
| Hero 主标题（桌面） | 24～38px | 28～44px 自适应 |
| Hero 介绍 | 13px | 15px |
| 区块标题 | 21px | 24px，移动端 22px |
| 工作台/快捷入口/技术支柱卡片标题 | 14px | 16px |
| 项目、任务、报告名称 | 12px | 14px |
| 快捷入口与能力说明 | 11～12px | 14px |
| 工作台说明和时间 | 10～11px | 12px |
| 生态说明、能力边界说明 | 9～11px | 12～14px |
| 状态标签 | 11px、24px 高 | 12px、26px 高 |

`HomeView.vue` 新增局部 `--home-font-*` 变量，首页与 `ResearchWorkbenchPanel.vue` 共用，后续可以统一调整。英文装饰眉题仍保持 11px，避免与主要内容争夺层级。

列表行高由 54px 调整至 62px，卡片内边距同步增加；次级正文改用既有 `--neutral-text-2`，提高深色背景下的可读性。保留长名称省略和完整 title、三列等宽、窄屏单列与减少动态适配。

- `npm run type-check`：通过。
- `npm test`：92 个文件、619 项测试通过。
- `npm run build`：通过，包括 prebuild 和 `vue-tsc -b`。
- 浏览器 1280/1440/2560/390px：无页面及首页容器横向溢出；默认 Hero 标题均为两行；桌面工作台三列等宽。
- 实际计算字号：任务/报告名称 14px、卡片标题 16px、说明/时间 12px；未使用 zoom 或 transform scale。
- 1440×1440 下 Hero 高约 458px，工作台标题 top≈688px，仍在首屏内。
- 真实项目、任务、报告 API 均返回 200，工作台无加载失败状态；浏览器 pageerror 为 0。

构建产物通过现有 `frontend/dist` 挂载提供；仅刷新 Nginx，未重启后端或执行数据库迁移。验证及截图见 `evidence/home-typography-20261021/`，不纳入提交。原有全量后端门禁失败与待确认的分阶段提交状态不在本次纯样式调整中处理。
